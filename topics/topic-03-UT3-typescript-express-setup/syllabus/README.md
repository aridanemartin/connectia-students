# Topic 03 — Syllabus

- Inicializar un proyecto Node.js (`package.json`) y conocer sus scripts.
- Explicar qué es un linter (ESLint), qué es un formateador (Prettier) y
  en qué se diferencian.
- Configurar TypeScript en modo `strict` y justificar las opciones del `tsconfig.json`.
- Diferenciar `Promise`, `async/await`, funciones tipadas e interfaces.
- Cargar variables de entorno desde `.env` de forma nativa
  (`process.loadEnvFile()`) y leerlas con valores por defecto.
- Distinguir crear la aplicación (`app.ts`) de arrancar el servidor (`server.ts`).
- Explicar qué contienen los objetos `req` y `res` que Express pasa a
  cada handler de ruta, y usarlos para leer la petición y construir la
  respuesta.
- Ejecutar el ciclo `install → typecheck → build → dev` y comprobarlo con `curl`.
- Construir el proyecto de forma incremental: cada actividad añade solo
  los ficheros que explica.
