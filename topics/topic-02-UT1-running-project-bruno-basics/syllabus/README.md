# Topic 02 — Syllabus

- Ubicar un proyecto Node.js, leer su `package.json` y ejecutar sus scripts (`install`, `dev`, `build`).
- Diferencia entre `.env` (no versionado) y `.env.example` (versionado).
- Enviar peticiones `GET` con Bruno y leer la anatomía de una respuesta HTTP (código, cabeceras, cuerpo).
- Escribir el `curl` equivalente a una petición de Bruno.
- Diagnosticar por terminal fallos de arranque: `.env` ausente, dependencia ausente, puerto ocupado.
