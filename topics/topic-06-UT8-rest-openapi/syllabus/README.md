# Topic 06 — Syllabus

- Modelar recursos y diseñar rutas orientadas a sustantivos.
- Elegir método HTTP y código de estado justificando su semántica.
- Distinguir datos de `path`, `query` y `body`.
- Definir contratos JSON de petición, respuesta y error.
- Escribir un documento OpenAPI 3.1 con `paths`, `parameters`, `requestBody`,
  `responses` y `components`.
- Validar el documento con Redocly y detectar una rotura deliberada.
- Comprobar la coherencia entre tabla de contrato, router y OpenAPI.
