# connectia-students

Material del **alumnado** del proyecto **Connectia** para la asignatura de
**Desarrollo Web en Entorno Servidor** (DSW) del curso 2026–2027 en el
**IES El Rincón**.

Durante el curso construiréis un backend con **Node.js + TypeScript + Express**
que consume un servicio de IA desarrollado por el profesorado como **caja
negra**. Este repositorio contiene únicamente el material de cada semana; no
es el repositorio de vuestro equipo.

## Contenido

Solo se publican aquí las semanas ya impartidas. El repositorio crece a medida
que avanza el curso.

## Estructura de cada semana

```text
topics/topic-NN-slug/
├── README.md      # guía de la semana (empieza por aquí)
├── code/          # código de ejemplo o demo ya construido por el profesorado
├── exercises/     # plantillas de las actividades del alumnado
├── syllabus/      # items que debes dominar al superar la semana
└── assets/        # (según la semana) diagramas y material de apoyo
```

## Cómo usar este repositorio

1. Abre la carpeta de la semana actual y lee su `README.md`.
2. Sigue las "Actividades del alumnado" en orden, usando las plantillas de
   `exercises/`.
3. Guarda las evidencias en la carpeta `team-docs/` de **tu repositorio de
   equipo**, no aquí.
4. Comprueba los "Criterios de aceptación" y la "Autoevaluación" antes de pasar
   a la semana siguiente.

## Idioma

Las explicaciones pedagógicas están en **español**. Los identificadores
técnicos (`npm`, `git`, rutas, nombres de ficheros, código) van en **inglés**.

## Entorno recomendado

- Node.js ≥ 20 LTS y Git ≥ 2.
- Visual Studio Code con las extensiones recomendadas en
  [`.vscode/extensions.json`](./.vscode/extensions.json): al abrir la carpeta,
  VS Code te ofrecerá instalarlas.
